# Actividades · semana del 23 al 27 de noviembre

Semana de repaso de toda la 1ª evaluación. La actividad es un proyecto completo, de principio a fin, que junta lo trabajado en la evaluación. No tiene cuestionario ni cuenta para la nota.

| Archivo | Qué es |
|---|---|
| [`guia-ValoraPROG.md`](guia-ValoraPROG.md) | Guía paso a paso de **ValoraPROG**, un programa en Java con menú en la terminal que recoge valoraciones del 1 al 5 y calcula sus medias, también en estrellas (`****-`), y una global con pesos que se pueden cambiar, repartido en tres clases (`Principal`, `Menu` y `Calculos`); además, muestra la mejor valoración y la mejor nota de cada categoría, modifica una ya guardada y crea 10 al azar: `Scanner`, `Random`, `switch`, bucles, métodos, una matriz y un array. **Empieza por aquí** |
| [`ValoraPROG.zip`](ValoraPROG.zip) | El proyecto terminado, para comparar con el propio |
| [`ejercicios-regex.md`](ejercicios-regex.md) | Repaso de las expresiones regulares y los arrays: deducir las carpetas y el paquete de un proyecto a partir de los comandos `javac` y `java`, validar códigos postales y DNI con `matches`, buscarlos en un texto con `Pattern` y `Matcher`, y un ejercicio de matrices para completar |
| [`regex.zip`](regex.zip) | El proyecto de `ejercicios-regex.md`, para abrirlo y continuar el ejercicio 3 |
