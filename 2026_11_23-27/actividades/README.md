# Actividades · semana del 23 al 27 de noviembre

Semana de repaso de toda la 1ª evaluación. La actividad es un proyecto completo, de principio a fin, que junta lo trabajado en la evaluación. No tiene cuestionario ni cuenta para la nota.

| Archivo | Qué es |
|---|---|
| [`guia-ValoraPROG.md`](guia-ValoraPROG.md) | Guía paso a paso de **ValoraPROG**, un programa en Java con menú en la terminal que recoge valoraciones del 1 al 5 y calcula sus medias, también en estrellas (`****-`), y una global con pesos que se pueden cambiar, repartido en tres clases (`Principal`, `Menu` y `Calculos`); además, muestra la mejor valoración y la mejor nota de cada categoría, modifica una ya guardada y crea 10 al azar: `Scanner`, `Random`, `switch`, bucles, métodos, una matriz y un array. **Empieza por aquí** |
| [`ValoraPROG.zip`](ValoraPROG.zip) | El proyecto terminado, para comparar con el propio |
| [`ejercicios-regex.md`](ejercicios-regex.md) | Repaso de las expresiones regulares y los arrays: deducir las carpetas y el paquete de un proyecto a partir de los comandos `javac` y `java`, validar códigos postales y DNI con `matches`, buscarlos en un texto con `Pattern` y `Matcher`, y un ejercicio de matrices, todo resuelto |
| [`repaso-arrays.md`](repaso-arrays.md) | El ejercicio de matrices del proyecto `regex`, explicado parte por parte: crear y rellenar una tabla de dos dimensiones, imprimirla y sumar una fila, una columna y la tabla entera |
| [`regex.zip`](regex.zip) | El proyecto de `ejercicios-regex.md`, con los tres ejercicios resueltos, para compilarlo y ejecutarlo |
| [`ejercicio-ausencias.md`](ejercicio-ausencias.md) | Guía paso a paso de **Ausencias**, un programa en Java que apunta las ausencias de 10 estudiantes de lunes a viernes: los nombres en un array de `String` y las ausencias en un array de `boolean` de dos dimensiones, con una clase de datos y otra de operaciones para buscar un estudiante, poner una ausencia e imprimir los ausentes de un día. Cada paso se compila y se comprueba |
| [`ausencias.zip`](ausencias.zip) | El proyecto terminado, para comparar con el propio |
