## Dónde consultar

- **Métodos de `String` y de `Math`:** la documentación oficial de Java 21, en inglés: [String](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/String.html) y [Math](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/Math.html). Busca el método con `Ctrl+F`: cada uno dice qué recibe, qué devuelve y qué hace.
