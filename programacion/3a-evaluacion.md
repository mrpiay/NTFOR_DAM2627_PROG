## Qué incluye cada entrega

| UD | Entrega | Qué incluye |
|---|---|---|
| UD8 | Mini-proyecto.Procesador de ficheros. | App «procesador-fx» que lee de datos/in/, transforma y escribe en datos/out/. logs/app.log y logs/erros validacion.log creados durante la ejecución. _ Pequeño README con uso: argumentos, rutas y ejemplos. |
| UD9 | Taller de estructuras | Resolución de varias katas centradas en List, Set y Map. Código limpio, comentado y con soluciones alternativas. Pequeño informe o README explicando la elección de las colecciones. |
| UD10 | Mini-módulo con Streams y Collectors | 6–8 ejercicios: refactorizar bucles a Streams, agregaciones, agrupaciones y particiones. Mini-módulo que procesa una lista (p.ej. Produto) con Collectors típicos. README corto con las decisiones tomadas y casos de prueba básicos. |
| UD11 | Taller de UI | 2–3 formularios funcionales (p.ej. registro, pedido y contacto). Pequeña utilidad Validador reutilizable. Checklist de pruebas: casos válidos/erróneos y capturas. |
| UD12 | Mini-proyecto BD, parte I: modelo y script SQL | Script SQL con la creación completa de la BD. Base de datos funcional lista para conexión JDBC. Documento o diagrama con el modelo entidad-relación. |
| UD13 | Mini-proyecto BD, parte II: persistencia con JPA | Proyecto funcionando con persistencia JPA (CRUD + 1–2 consultas JPQL). Código migrado: DAO antiguo → Repository JPA, manteniendo la interfaz pública. README corto con pasos de ejecución y cambios clave de la migración. |
| UD14 | Taller CRUD OO | Aplicación funcional que permite crear, consultar, modificar y eliminar objetos. Código documentado y probado con ejemplos reales de persistencia. |
